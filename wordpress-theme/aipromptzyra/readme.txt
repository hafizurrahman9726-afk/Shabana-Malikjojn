== Description ==

AIPromptzyra is a dedicated, ultra-fast WordPress theme crafted for AI prompt portals, prompt engineers, and creative communities.

Features:
* Custom Post Type 'prompt' with taxonomy categories & styles
* Interactive 8-field AI Prompt Builder with live copy and Gemini deep-linking
* Clean semantic HTML5 and accessible WCAG-compliant design
* Built-in dark / light theme switcher stored in localStorage
* Real-time search with instant category filters
* SEO-ready markup compatible with Yoast SEO, Rank Math, and All in One SEO
* Zero external heavy JavaScript dependencies (pure vanilla ES6+)
* Gutenberg & block editor support
* Complete Customizer integration for colors, hero copy, and footer settings

== Installation ==

1. In your WordPress admin dashboard, navigate to Appearance > Themes.
2. Click "Add New" and then "Upload Theme".
3. Upload the `aipromptzyra.zip` file.
4. Click "Install Now" and then "Activate".
5. Navigate to Appearance > Menus to assign your Primary and Footer menus.
6. Navigate to Appearance > Customize to customize hero text and branding colors.

== Frequently Asked Questions ==

= Does this theme require any page builder? =
No. The theme is built using lightweight native WordPress templates, semantic HTML5, and vanilla JavaScript for maximum speed and Core Web Vitals performance.

= How do I add AI prompts? =
Navigate to Prompts > Add New in your admin sidebar. You can set the featured image, category, prompt formula, and optional negative prompt.
